# ГРЯЗЬ · выкладка v11 на РФ-хостинг

Всё живёт на одном shared-хостинге с PHP 8 и SQLite. Рекомендация по разведке 21.09.2026: **Timeweb, тариф Year** — 393 ₽/мес или 2 928 ₽/год, 10 дней бесплатно, HTTPS на техническом домене `логин.tw1.ru` сразу (нужно для PWA), PHP до 8.4, SSH. При заказе выбрать дата-центр **Россия** (это требование закона о локализации, не вкус).

## 1. Хостинг (15 минут, руками)
1. Регистрация на timeweb.com как физлицо, оплата российской картой (это и есть идентификация, паспорт не нужен).
2. Панель → PHP → версия 8.2+. Залить в корень сайта файл `phpinfo.php` с `<?php phpinfo();` и открыть в браузере: найти `pdo_sqlite` → **enabled**. Нет — писать в поддержку или брать Beget.
3. Удалить `phpinfo.php`.
4. Написать в поддержку: «Подтвердите, пожалуйста, страну и адрес дата-центра, где размещён мой сайт, и где хранятся резервные копии» — ответ сохранить (нужен для уведомления РКН и политики).

## 2. Файлы (5 минут)
Структура на сервере (`public_html/`):
```
index.html  sw.js  manifest.webmanifest  icons/        ← приложение
terms.html  consent.html  consent-health.html  policy.html
coach/index.html                                        ← кабинет тренера
api/index.php  api/admin.php  api/.htaccess  api/config.php  api/data/.htaccess
```
1. Скопировать `server/api/config.php.example` → `server/api/config.php`, вписать длинный случайный `admin_key` (например, 40 символов из менеджера паролей). `origins` оставить с GitHub Pages на время переезда, потом очистить.
2. Залить всё по SFTP/SSH (или через файловый менеджер панели). `api/data/` должна быть **доступна на запись** для PHP (права 750/770 — обычно так и есть).
3. Открыть `https://ДОМЕН/api/index.php?r=ping` → `{"ok":true,...}`. Открыть `https://ДОМЕН/api/data/` → должно быть 403.

## 3. Тренер (2 минуты)
`https://ДОМЕН/api/admin.php?key=ТВОЙ_КЛЮЧ` → логин `dima`, имя `Дмитрий`, пароль от 8 символов → «Создать». Логин и пароль отдать Диме лично (не в общий чат).

## 4. Реквизиты в документах (10 минут)
В `legal/build.py` заполнить блок `OPERATOR` (ФИО, адрес, e-mail, хостер и адрес ЦОД) и запустить `python legal/build.py` — пересоберутся четыре html-страницы. Залить их заново.

## 5. Переезд с GitHub Pages
- В `index.html` константа `API_DEFAULT` = `https://ДОМЕН/api/index.php` — тогда установка с GitHub Pages тоже ходит на РФ-сервер. Запушить в main.
- На телефоне: открыть старую установку → История → Тренер → Подключиться по коду → данные уйдут на сервер. Затем открыть `https://ДОМЕН/` в Safari → История → Тренер → «Забрать с сервера» (сперва подключиться кодом «для нового телефона» из кабинета) → «Добавить на экран Домой». Старую иконку удалить.
- Когда все переехали: `origins` в config.php → `[]`, в репозитории GitHub Pages оставить заглушку с новым адресом.

## 6. Закон — до первого чужого клиента
Порядок и шпаргалки в `legal/`:
1. Реквизиты в документах и публикация страниц (п. 4).
2. Подписать с Димой «Поручение тренеру» (бумага, две подписи, скан себе).
3. Подать уведомление в Роскомнадзор через Госуслуги — поля в «РКН уведомление — что заполнять.md». Бесплатно, 20 минут.
4. Каждому клиенту в зале — «Согласие бумажное (для зала)» под подпись; скан — в папку у себя, не на сервер. В приложении он проходит те же три экрана согласий.
5. Заполнить «Оценка вреда» (полстраницы) и положить рядом с актами уничтожения.
6. Регламент инцидента прочитать один раз, чтобы знать адрес формы.

## 7. Бэкапы базы
Раз в неделю: панель хостинга → бэкап, либо по SSH `sqlite3 api/data/gryaz.sqlite ".backup /home/…/backups/gryaz-$(date +%F).sqlite"`. Хранить только на хостинге или на своём диске в России; в Google Drive/iCloud — нельзя (локализация).

## Проверка после выкладки
- `https://ДОМЕН/api/index.php?r=ping` отвечает.
- Кабинет открывается, вход работает, код приглашения создаётся.
- На телефоне: подключение по коду → «Отправить всё» → в кабинете клиент появился с весом и тренировками.
- В кабинете: Программа → изменить упражнение → «Отправить» → на телефоне через минуту тост «Тренер обновил программу».
- «Отключиться и стереть» → клиент исчез из кабинета; в базе `SELECT * FROM wipes;` есть запись.
