# Уведомление в Роскомнадзор об обработке персональных данных — шпаргалка по полям

Где: https://pd.rkn.gov.ru/operators-registry/notification/form/ → вход через Госуслуги (подтверждённая учётная запись, ЭП не нужна).
Когда: ДО первого чужого клиента. РКН вносит в реестр до 30 дней, ждать не обязательно.
Стоимость: 0 ₽. Штраф за неподачу для физлица: 5–10 тыс. ₽ (ч. 10 ст. 13.11 КоАП).
Изменения (новый тренер, новые категории данных, фото на сервер) — сообщить до 15-го числа следующего месяца (ч. 7 ст. 22).

| Поле формы | Что писать |
|---|---|
| Тип оператора | Физическое лицо |
| ФИО, адрес, ИНН | свои |
| Территориальный орган | Управление Роскомнадзора по Иркутской области |
| Правовое основание | ст. 6 ч. 1 п. 1 и ст. 10 ч. 2 п. 1 152-ФЗ (согласие субъекта, в т. ч. письменное на данные о здоровье); ст. 6 ч. 1 п. 7 (журналы безопасности) |
| **Цель 1** | Ведение пользователем дневника тренировок, питания, сна и веса и предоставление данных его тренеру для контроля тренировочного процесса |
| — категории субъектов | Пользователи приложения ГРЯЗЬ (клиенты тренеров), совершеннолетние |
| — категории ПДн | Иные: имя/ник; специальные: сведения, которые могут расцениваться как данные о состоянии здоровья — вес тела, тренировки (веса, повторы), дневник питания (калории, БЖУ), время сна, отметки чек-листа; технические: IP-адрес, user-agent, идентификатор устройства |
| — действия | сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, предоставление (тренеру), блокирование, удаление, уничтожение |
| — способ | с использованием средств автоматизации (веб-приложение и сервер) |
| **Цель 2** | Работа кабинета тренера |
| — субъекты | Тренеры-пользователи кабинета |
| — ПДн | имя, логин, хэш пароля, технические данные |
| Обработка по поручению | Да: тренер (ФИО) — просмотр данных клиентов и составление программ в кабинете по поручению оператора (ч. 3 ст. 6) |
| Меры по ст. 18.1 и 19 | политика опубликована (policy.html); HTTPS; токены доступа в виде хэшей; разграничение доступа; минимизация (нет ФИО/контактов/фото); резервные копии в РФ в зашифрованном виде; журнал уничтожения; ограничение попыток входа; оценка вреда и внутренний контроль |
| Шифрование | используется: TLS при передаче; хранение на сервере в РФ |
| Ответственный | сам оператор, контакт: [e-mail], [телефон] |
| Дата начала обработки | дата первого чужого клиента (или дата подачи) |
| Срок/условие прекращения | до отзыва согласия субъектом или прекращения работы сервиса |
| Трансграничная передача | не осуществляется |
| Место нахождения базы данных | Россия: [наименование хостера, ИНН, адрес дата-центра] — взять у поддержки хостинга письменно |

После отправки сохранить регистрационный номер и «ключ» записи (нужны для изменений и для формы инцидента).
