# ГРЯЗЬ. ХОЗА ХОЗА

Уличный трекер тренировок. Турник, брусья, путь на 70 кг.

- Три дня A/B/C (тяга / жим / ноги), прогрессия «прошлый раз + 1 повтор»
- График веса тела к цели 70 кг
- История тренировок по датам
- PWA: ставится на телефон как приложение, работает офлайн
- Данные в localStorage + экспорт/импорт бэкапа в JSON

Стек: один HTML-файл, ноль зависимостей.
